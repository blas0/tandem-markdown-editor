## Beautiful UI

The document table adapts https://www.beautifului.dev/r/filter-table.json using Tandem’s existing tokens. The review trace and proposed-edit table adapt the Thinking and Diff Table interaction patterns from https://www.beautifului.dev/r/thinking-state.json and https://www.beautifului.dev/r/diff-table.json. Tandem supplies its own review units, progress, diff rendering and decisions; the demonstration data and timers are not included.
